# 🔎 Markov Password Strength Analyzer

A Python-based tool that analyzes password strength using a simplified Markov Chain model.

## 🚀 Features
- Detects predictable password patterns
- Scores password strength
- Classifies as Weak / Moderate / Strong

## 🛠️ Tech Used
- Python
- Collections (defaultdict)

## ▶️ How to Run
```bash
python main.py
📌 Example
Enter password: abc123
📷 Output
Score: 12
Strength: Weak
📚 Concept

Uses probability of character sequences to determine predictability of passwords.
